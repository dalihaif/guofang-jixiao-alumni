# 国防技校同学录

一套**纯静态**的校友同学录网站（HTML + CSS + JavaScript），无需服务器、无需数据库。
面向对象：云南省国防技校往届在校学员（当前内容以 **钳工七班 1992—1995** 为主）。

## 在线访问

GitHub Pages：<https://dalihaif.github.io/guofang-jixiao-alumni/>

## 栏目

| 栏目 | 文件 | 说明 |
|------|------|------|
| 首页 | `index.html` | 开篇寄语、老照片轮播、同窗寄语滚动、大事记 |
| 同窗名录 | `roster.html` | 按届别/班级/身份检索，同学卡片，隐私保护 |
| 岁月相册 | `album.html` | 四类相册、上传与预览、影音资料 |
| 留言板 | `messages.html` | 在线留言、回复、我的留言 |
| 校园往事 | `stories.html` | 《国防技校的日子》全文 + 大事记 |
| 登录 / 注册 / 我的资料 | `login.html` `register.html` `profile.html` | 简易账号系统、隐私开关 |
| 管理后台 | `admin.html` | 留言审核、照片审核、用户管理、数据备份 |
| 关于本站 | `about.html` | 建站初衷、隐私约定、免责声明、使用帮助 |

## 本地运行

```bash
# 方式一：直接双击 index.html
# 方式二（推荐）：
python -m http.server 8080   # 然后访问 http://127.0.0.1:8080
```

## 改内容

**所有文字、名单、文章、照片清单都集中在 `js/seed.js`**，改完保存刷新即可。
配色改 `css/style.css` 顶部的 `:root` 变量。详见仓库内 `使用说明.md`。

## 设计要点

- **隐私优先**：名录不存联系方式；同学"认领"自己的词条后自行开关手机号/地址，默认全部关闭，
  未公开时连管理员也看不到。
- **内容审核**：留言与照片提交后进入待审核，管理员通过后才会对外展示。
- **轻量**：静态页面 + 浏览器本地存储，不上传服务器、不接第三方、不含广告。

## 声明

本网站为**校友民间自建**，非学校官方网站，与学校及任何单位无隶属关系。
站内内容仅为同学之间的回忆与联络之用，不含任何涉密或军事内容。
