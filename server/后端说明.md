# 后端说明（Flask + SQLite）

## 它解决什么问题

纯静态版的数据存在**各自浏览器**里，同学 A 写的留言，同学 B 看不到。

加上这个后端后，所有人的留言、照片、注册账号都存进同一个 SQLite 数据库，
**大家看到的是同一份数据**。

## 一分钟启动

```bash
# 1. 装依赖（只需一次）
pip install flask

# 2. 启动
python server/app.py              # 本机访问 http://127.0.0.1:5000
python server/app.py --host 0.0.0.0   # 局域网同学一起访问
```

Windows 用户也可以直接双击根目录的 **`启动服务.bat`**。

启动后浏览器打开 **http://127.0.0.1:5000** 即可，网址里不用带 `index.html`。

## 两种模式自动切换

前端一打开会探测 `/api/ping`：

| 情况 | 模式 | 数据存在哪 |
|---|---|---|
| 通过 `server/app.py` 打开 | **服务器模式** | 后端 SQLite，所有人共享 |
| 直接双击 `index.html`、GitHub Pages、内网共享文件夹 | **本地模式** | 各自浏览器的 localStorage |

**不需要改任何代码**，也不用重新部署。GitHub Pages 上的静态版照常工作（会自动降级为本地模式）。

想强制只用本地模式：在 `js/seed.js` 顶部加一行 `window.FORCE_LOCAL = true;`

## 文件说明

```
server/
├─ app.py              # 全部后端代码（单文件，约 500 行）
├─ requirements.txt    # 只依赖 Flask
├─ data/alumni.db      # 数据库（首次启动自动生成）★ 这就是全部数据
└─ uploads/            # 同学上传的照片（原始图会落盘，不塞进数据库）
```

## 数据库表

| 表 | 内容 |
|---|---|
| `users` | 注册账号（口令用 werkzeug 加盐哈希，不明文） |
| `members` | 同窗名录（含 `owner_id` 认领关系与隐私开关） |
| `messages` / `replies` | 留言与回复，带 `status` 审核状态 |
| `photos` | 照片（内置照片存路径，上传照片存 `/uploads/xxx.jpg`） |
| `logs` | 管理员操作日志 |

## 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ping` | 前端探测后端是否可用 |
| GET | `/api/state` | 一次性拉取全部数据（未审核内容只给管理员和作者本人） |
| POST | `/api/seed` | 首次启动由 `js/seed.js` 灌入初始内容 |
| POST | `/api/register` `/api/login` | 注册 / 登录（登录返回随机 token） |
| POST | `/api/password` | 修改密码 |
| GET/POST/DELETE | `/api/users*` | 用户管理（管理员） |
| POST | `/api/members/<id>/claim` | 认领名录条目 |
| PUT | `/api/members/<id>/profile` | 保存联系方式与隐私开关 |
| POST | `/api/messages*` | 留言、回复、审核、删除 |
| POST | `/api/photos*` | 上传照片（base64 落盘）、审核、删除 |
| GET | `/api/logs` `/api/backup` | 操作日志、数据备份 |
| POST | `/api/reset` | 恢复初始数据（管理员，危险） |

需要管理员权限的接口会校验 `X-Auth-Token` 请求头与 `role=admin`。

## 备份与迁移

**最省事的办法：直接复制 `server/data/alumni.db` 这一个文件。**
它就是全部数据（SQLite 单文件）。换电脑时把它拷过去覆盖即可。

也可以在管理后台"数据备份"页导出 JSON。

## 安全说明（请读一遍）

这是面向小范围校友的内网 / 小站方案，做到了：

- 口令用 `werkzeug.security` 加盐哈希，数据库里没有明文密码；
- 登录用随机 token，不用自增 id 冒充身份；
- 管理员接口校验角色；普通用户只能删自己的留言和照片；
- 联系方式默认不入库展示，只有本人开启开关后才会出现在名录里；
- 未审核内容只对管理员和作者本人可见。

但它**不是公网级防护**。如果要放到公网，至少还要做：

1. 上 HTTPS；
2. 登录失败次数限制（防暴力破解）；
3. 把默认管理员密码 `admin888` 改掉；
4. 用 gunicorn / waitress 之类的生产 WSGI 服务器替代 Flask 自带的开发服务器；
5. 定期备份 `alumni.db`。

## 常见问题

**Q：启动报 `Address already in use`？**
A：5000 端口被占用。换端口：`python server/app.py --port 8080`

**Q：同学访问不到我的地址？**
A：确认用了 `--host 0.0.0.0`，且两台电脑在同一个局域网；Windows 防火墙可能拦了，
   需要在防火墙里放行 Python。

**Q：改了 `js/seed.js`，后端数据没变？**
A：`/api/seed` 只在数据库为空时执行。想重来：管理后台 → 系统设置 → 恢复初始数据。

**Q：不想要后端了？**
A：直接不启动它就行，网站会自动回到本地模式，功能完全不受影响。
